
   TMUX — AIDE-MÉMOIRE        (préfixe = ⌘b ou Ctrl-b)
   ════════════════════════════════════════════════════

   ▸ LIRE LA BARRE DU BAS
       bloc session ORANGE  le préfixe est armé : tmux attend ta touche
       ●  sur un onglet     le Claude de cette fenêtre t'attend
                            (il a fini, ou il demande une permission)
       « pro ● » à droite   un Claude t'attend dans une AUTRE session
        main  à droite    branche git du pane actif
         sur un onglet     un pane est zoomé (préfixe z pour revenir)
       titre en haut        quand la fenêtre est découpée : n° · dossier · commande

   ▸ CLAUDE
       préfixe  a           aller au prochain Claude qui t'attend (toutes sessions)
       préfixe  A           tableau de tous les Claude : bloqué / à toi / travaille,
                            contexte, effort, ce qu'il fait (en direct, Entrée = y aller)
       préfixe  N           historique des notifications Claude (Entrée = y aller)
       bannière macOS       triée par l'IA, seulement si tu n'es pas dans Alacritty :
                              🔴 décision (avec son) · 🟡 à relire · ⚪ info (pas de bannière)
                              🔐 permission : la commande + son risque (✓ ⚠ ⛔)
                              ⚠️ un Claude qui tourne en rond depuis 10 min
                            clic = y aller
       bouton Autoriser     sur une permission Bash courte : valide sans y aller
                            (refusé si l'écran ne montre plus cette commande exacte)

   ▸ PANES  (les cadres dans une fenêtre)
       ⌥ ← / → / ↑ / ↓      aller au pane gauche/droite/haut/bas   ← SANS préfixe
                            (pas de pane de ce côté : ⌥←/→ saute un mot)
       ⌘ ← / →              début / fin de ligne (zsh, Claude)
       préfixe  v           split en COLONNES (côte à côte  | )
       préfixe  s           split en LIGNES  (l'un sous l'autre - )
       préfixe  z           ZOOM plein écran le pane / dézoom
       préfixe  x           fermer le pane
       préfixe  H/J/K/L      redimensionner (garde le préfixe, répétable)
       préfixe  Ctrl+h/j/k/l échanger le pane avec son voisin (direction)
       préfixe  Ctrl+o       faire tourner tous les panes

   ▸ FENÊTRES  (les onglets, en bas)
       Shift ← / →          fenêtre précédente / suivante          ← SANS préfixe
       préfixe  c           nouvelle fenêtre
       préfixe  ,           renommer la fenêtre
       préfixe  &           fermer la fenêtre
       préfixe  w           vue arborescente fenêtres + sessions

   ▸ SESSIONS  (tmux continue de tourner même fermé)
       préfixe  S           CHANGER DE SESSION (liste, tape, Entrée)
       préfixe  Tab         chercher une fenêtre ou une session (tape, Entrée)
       préfixe  ( / )       session précédente / suivante
       préfixe  d           se détacher (revient au shell)
       tmux a               se rattacher    (dans le shell)
       tmux new -A -s nom   ouvrir la session "nom" (la crée si absente)
                            ⚠ `tmux new nom` lance nom comme COMMANDE, pas un nom
       préfixe  Ctrl+s      sauvegarder les sessions maintenant
       préfixe  Ctrl+r      restaurer les sessions sauvegardées
                            (auto : sauvegarde /15 min, restauration au reboot)

   ▸ OUTILS / DIVERS
       préfixe  g / G       lazygit  (popup / fenêtre)
       préfixe  h           hunk — review du diff courant, NON commité (popup)
       préfixe  b           hunk — choisir un commit dans l'historique et le
                            relire (Échap sort, quitter hunk revient à la liste)
       préfixe  e           Zed — ouvre le projet courant (l'IDE : lire, naviguer)
                            ⌘P fichier · ⌘⇧F chercher · ⌘clic définition
       préfixe  D           lazysql — bases de données (popup)
       préfixe  [           mode défilement/copie   (q pour sortir)
       préfixe  r           recharger cette config
       préfixe  ?           afficher cet aide-mémoire

   ────────────────────────────────────────────────────
   POUR APPRENDRE  (une couche à la fois) :
     Jour 1 → ⌥hjkl (panes) + préfixe v/s (split) + préfixe z (zoom)
     Jour 2 → Shift←/→ (fenêtres) + préfixe c (nouvelle)
     Jour 3 → préfixe d / tmux a (sessions) + préfixe [ (copie)
   La souris marche aussi : clic sur un pane / un onglet.   (q = fermer)
